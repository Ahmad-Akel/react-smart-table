# React Smart Table 🚀

A powerful, flexible, and easy-to-use table library for React and Next.js.

With React Smart Table, you can effortlessly display and manage data with features like sorting, pagination, column customization, theming, and editing—all while keeping things fast and lightweight.

🔹 Built for modern web apps

🔹 Highly customizable & extensible

🔹 Supports real-time editing & data management

## Features ✨

✅ Render Data Dynamically – Simply pass an array of objects, and React Smart Table will generate headers and rows automatically.

✅ Column Visibility Control – Toggle column visibility using a popup with checkboxes.

✅ Custom Row Actions – Each row can have an action popup for custom operations.

✅ Sorting – Click on column headers to sort data.

✅ Pagination & Rows Per Page Selector – Easily navigate  
large datasets with pagination and a dropdown to control rows per page.

✅ Theming Support – Customize the look and feel of the table to match your app’s design.

✅ Column Type Identification & Validation – Define the type of each column (both existing and newly added), with input validation based on the column type.

✅ Edit Mode – Update table data and headers directly within the table.

✅ Dynamic Column & Row Management – Add new columns and rows at any index (left, right, above, below), and delete columns or rows as needed.
